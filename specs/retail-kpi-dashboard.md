# Retail KPI dashboard

Status: approved | Date: 2026-11-09 (round 2: persona review fixes, same day; round 3: second persona review, 2026-11-10) | Owner: Modestas

## Goal
An ops manager's Monday KPI review takes a spreadsheet pull and hand-typed figures. This Streamlit dashboard shows 53 weeks of a real online retailer's sales (UCI Online Retail II): weekly KPIs with week-over-week changes, trends, flagged weeks with their reason, and a CSV export. Every number is computed in code, traceable to its formula and inputs, and the same everywhere it appears.

## In scope
- Data build: download the raw UCI file (SHA-256 checked), clean it with the rules of DEC-04, write small derived tables without customer ids to `data/derived/` (committed with attribution).
- Calc core (no Streamlit imports): weekly KPIs per country filter, week-over-week changes, range totals, top 5 products and countries, flags with reasons, formula-and-inputs text per KPI, CSV export.
- Saved weekly summaries from an earlier offline run, shown read-only for All countries only, with the label in DEC-14.
- Streamlit app, 5 pages via `st.navigation`: Overview, Trends, Flagged weeks, Weekly table, Methodology & data.
- Shared sidebar: preset, date range, country, week, Reset.
- Dark navy theme in one theme file + `.streamlit/config.toml` + one CSS file + one Plotly template.
- Playwright screenshots at 1280 and 1440 px, README.
- Round 2 (persona review): swing flags vs the trailing 4-week average at 40% with plain-English flag labels; no-data week drawn as a gap and the partial week drawn hollow with a note; one quiet range line instead of the range strip; the week's summary headline under the title with the full summary in an expander; a flag status pill with details on click; 3 big cards with 12-week sparklines and 7 small ones; Trends polish (DEC-21); top lists with share bars and title-case names; Flagged weeks grouped by week; Weekly table with the Week column pinned, coloured changes and flag labels; one font family, tabular numbers, app name at the top of the sidebar, "Data as of" line; a "With your data" line on Methodology.
- Graphite pass (owner pick after round 3): shared Graphite theme and system font, a 3-line reading strip on each data page, plain words first in every ? help (DEC-16, DEC-19, DEC-29..31).
- Round 3 (second persona review): net revenue (revenue after cancellations) is the headline KPI everywhere, gross is secondary; swing flags use net revenue; a computed one-sentence headline on top (no AI), the saved AI summary only in a labelled expander; year-over-year changes on the 3 big cards (the build adds the year before as comparison bases); top 3 drivers for every swing flag; one "Placed and cancelled" flag instead of a big order plus large cancellations when an order is cancelled the same week; one cancellation metric on the cards; Trends, Weekly table and visual polish (DEC-26..DEC-29).

## Out of scope
- Any AI or network call at runtime; regenerating summaries.
- Deploying to Streamlit Community Cloud (prepared only; deploy is an owner step).
- Multi-select countries, custom flag thresholds, day-level date filtering (dates snap to ISO weeks).
- Margins, stock, returns other than cancellations (the dataset has none).
- Netting cancellations against the week of the original order.
- Customer-level views; customer ids never leave the build step.
- Login, user accounts, saving views.
- Margin, stock and targets (no data); a walkthrough video; a Monday email digest; a wholesale vs retail split.
- Matching a cancellation to an order placed in an earlier week (placed-and-cancelled matches the same week only, DEC-25).
